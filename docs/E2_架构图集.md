## 2. 数据流架构

### 2.1 设备数据上报流

```
设备 ──MQTT PUBLISH──→ MQTT Broker
                         │
         ┌───────────────┼───────────────┐
         │               │               │
         ▼               ▼               ▼
   告警规则评估      SSE 实时推送     写入 MySQL
   alarm_evaluate    sse_broadcast    data_writer
         │               │               │
         ▼               ▼               ▼
   生成告警记录      推送到客户端     data_YYYYMM
   alerts 表        QML 图表更新     按月分表
```

### 2.2 指令下发流

```
客户端 ──HTTP POST──→ handler_command
                         │
                    查找设备连接
                         │
              ┌──────────┴──────────┐
              │                     │
          设备在线              设备离线
              │                     │
         MQTT PUBLISH          入队离线队列
         cmd/{id}/exec         cmd_mgr_enqueue
              │                     │
          设备执行              设备上线后下发
```

### 2.3 告警处理流

```
数据上报 ──→ alarm_evaluate()
                │
          匹配告警规则
                │
         ┌──────┴──────┐
         │             │
      命中规则      未命中
         │             │
    写入 alerts     忽略
         │
    SSE 广播告警
         │
    客户端展示
```
