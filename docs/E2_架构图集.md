## 2. 数据流 — 设备上报

```mermaid
sequenceDiagram
    participant Dev as IoT 设备
    participant MQTT as MQTT Broker
    participant Alarm as 告警引擎
    participant DB as MySQL
    participant Client as Qt 客户端

    Dev->>MQTT: PUBLISH devices/{id}/data
    MQTT->>MQTT: 解析 JSON payload
    MQTT->>Alarm: alarm_evaluate()
    
    alt 触发告警
        Alarm->>DB: INSERT INTO alerts
        Note over Alarm: 告警写 alerts 表，客户端经 REST 查询
    end

    MQTT->>DB: INSERT INTO data_YYYYMM
    Note over MQTT: 数据点落库，客户端经 REST 轮询刷新
    Client->>Client: 更新实时图表
```

## 3. 数据流 — 指令下发

```mermaid
sequenceDiagram
    participant Client as Qt 客户端
    participant HTTP as HTTP API
    participant CMD as 指令服务
    participant MQTT as MQTT Broker
    participant Dev as IoT 设备

    Client->>HTTP: POST /api/command
    HTTP->>CMD: 查找设备连接

    alt 设备在线
        CMD->>MQTT: mqtt_broker_send_cmd()
        MQTT->>Dev: PUBLISH cmd/{id}/exec
        Dev-->>MQTT: ACK
        CMD-->>HTTP: status=delivered
        HTTP-->>Client: 200 {"status":"delivered"}
    else 设备离线
        CMD->>CMD: cmd_mgr_enqueue_offline()
        CMD-->>HTTP: status=queued
        HTTP-->>Client: 202 {"status":"queued","command_id":"cmd_xxx"}
    end
```

## 4. 数据流 — 告警处理

```mermaid
flowchart LR
    A["MQTT 数据上报"] --> B["alarm_evaluate()"]
    B --> C{"匹配规则?"}
    C -->|是| D["INSERT INTO alerts"]
    C -->|否| E["忽略"]
    D --> F["写 alerts 表"]
    F --> G["客户端 REST 轮询获得告警"]
    G --> H["QML 展示告警"]
    
    I["用户确认"] --> J["POST /api/alarm<br/>action=acknowledge"]
    J --> K["UPDATE alerts<br/>SET status=acknowledged"]
    
    L["用户解决"] --> M["POST /api/alarm<br/>action=resolve"]
    M --> N["UPDATE alerts<br/>SET status=resolved"]
```
